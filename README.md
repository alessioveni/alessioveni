# 💫 About Me:
M.Sc. Computer Engineering student at the University of Padua, focusing on network and information security.<br>
Co-Founder & CTO of [Deskk](https://deskk.ai), an AI agent that learns front-desk work from hotel staff and then runs it autonomously.

# 📂 Selected Projects:
- **[alpha-euclidean-mst](https://github.com/alessioveni/alpha-euclidean-mst)**: Euclidean minimum spanning trees with edge-weight constraints, based on Prim's algorithm (Java).
- **[Maglev](https://github.com/alessioveni/Maglev)**: simulation and control of a magnetic levitation system (Automatic Control, UniPD).
- **[MapAdapter](https://github.com/alessioveni/Progetto-EDIDS-MapAdapter)**: Software Engineering team project (UniPD).
- **[Bias & Fairness](https://github.com/alessioveni/Strumenti-di-valutazione-di-Bias-e-Fairness)**: bias and fairness evaluation tools (UniPD course project).
